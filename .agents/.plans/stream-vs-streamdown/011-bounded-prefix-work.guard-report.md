## Spirit

The plan's purpose was to stop per-frame cost from scaling with document length without breaking component ownership. The executor measured first (A/A control, three prefix sizes, per-cost counters), landed the sound O(1) items, and then designed rather than assumed the rendering change: it rejected the plan's own index-based segment sketch because an existing #328 case shifts indices without shifting offsets, and chose offset-bucket segments where a root's owner is a pure function of the same offset that is its key — so a root can never change owner, and streamed and one-shot renders produce identical markup. It also found and fixed a latent bug (two updates before one render kept the later metadata start index) with a red test. Guard read `prepareRootSegments`: kept segments are reused by object identity, only the touched bucket and the tail are rebuilt, and mismatched start offsets fall back to a full rebuild. Spirit met; the honest miss on the 15% criterion is a property of the benchmark's forced whole-document layout, which the acceptance contract should treat as environment, not renderer work (see follow-ups).

## Residual risk / follow-ups

- `reuseStableTokenArrayInPlace` writes reused prefix objects into the array the parser also keeps as `prevTokens`; sound today (the divergence scan starts past the prefix and the written objects are semantically equal), but it couples component and parser state — a reviewer should keep that invariant in mind for future parser changes.
- `streamRenderMetadataConsumed` is set from inside the `tokens` derived (plain `let`, non-reactive); works, but it is a side effect in a derived — flag in review.
- The batch contract's "384 KB within 15% of 24 KB" should be restated in terms of renderer work (flush + JS outside flush) or the harness should stop forcing a whole-document layout each frame; decide at batch close.
- Segment span 4,096 chars untuned; SSR/hydration with segmented markup has no dedicated test (each blocks add comment anchors only).
- Plan 010's flush-measure rise did not reproduce in this plan's A/A (symmetric within 2.5–8.8%); still unexplained but not a harness artifact.
