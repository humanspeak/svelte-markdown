## Goal and acceptance contract

Goal: on every scenario in `src/routes/test/stream-compare/+page.svelte`, at
one cumulative update per frame, do less main-thread work per frame than
svelte-streamdown 4.2.0 with zero frames over 16.7 ms, while rendering
semantically identical output to a fresh one-shot parse at every measured
intermediate state.

The batch is DONE only when all of the following hold on the paired protocol
from Plan 006 (same build of the competitor, alternating order, ≥ 5 measured
iterations after a warmup, run twice):

- `parityMismatches === 0` for every scenario and every sampled frame.
- Ours `totalWorkMsMedian` < Streamdown's on `prose-mixed`, `long-list`,
  `long-code-fence`, `citations`, `prefix-384kb`, `large-closed-block`.
- Ours `framesOverBudget === 0` on every scenario (target p95 renderer work
  ≤ 8 ms — a target, not a guarantee).
- `prefix-384kb` average work within 15% of `prefix-24kb` (bounded work).
- No scenario regressed by more than 3% relative to its Plan 006 baseline.

Plan-level numbers below are milestones toward this contract, not
completion criteria. Beating the competitor while any frames remain over
budget, or hiding latency by skipping/coalescing additional updates, does not
complete the initiative.

## Findings considered and rejected / deferred

- Two-`{#each}` prefix/tail split — rejected: Svelte each blocks do not
  transfer items across owners; completed blocks would remount.
- `Array.isArray`-only child validation — rejected: table `align` arrays
  contain `null`; comparator would throw.
- Observing list prop churn via `text`/`raw` props of a custom text renderer —
  rejected as an observable: child token fields override the parent's in the
  spread, and a custom text renderer disables the inline fast path. Use the
  dev-only Parser update counter with default renderers (010).
- Adaptive flush pacing (skip frames when a flush is slow) — rejected for
  this batch: it hides latency rather than removing work.
- Throttling syntax highlighting of an open fence — deferred to the
  extensions package; highlighting is off in the comparison.
- Label-scoped avoidance of the full re-lex — folded into 009 Part B as a
  targeted, seeded re-lex rather than a skip.
